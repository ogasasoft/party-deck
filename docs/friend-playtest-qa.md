# 友人プレイ前QA

初回実施日: 2026-05-18
更新日: 2026-06-05

## 目的

友人にスマホ1台を渡して遊んでもらう前に、3ゲームが最後まで進むこと、秘密情報がリロードで露出しないこと、ゲーム間で状態が混ざらないことを確認する。

## 実施結果

### ナンバートーク

- 4人で開始できた。
- 数字確認を4人分進められた。
- 会話、並び順、結果まで進められた。
- 並び順から結果へ直接進み、結果画面で初めて数字が表示された。
- 数字確認画面でリロードすると、直接数字は表示されず受け渡し画面へ戻った。

判定: OK

### ワンナイト人狼

- 4人で開始できた。
- 役職確認を4人分進められた。
- 夜行動、議論、秘密投票、結果まで進められた。
- 結果画面に処刑対象、最終役職、最初の役職、投票先が表示された。
- 役職確認画面でリロードすると、直接役職は表示されず受け渡し画面へ戻った。

判定: OK

### 日本マップ当て

- 4人、1地点で開始できた。
- 4人が同じ地点を回答し、結果へ進められた。
- 回答確認画面でリロードすると、回答ピン確認画面ではなく画像画面へ戻った。
- Mapillary画像とattributionリンクが表示された。

判定: OK

## 残りの確認

- iPhone Safari実機で縦画面確認する。
- Android Chrome実機で縦画面確認する。
- 実際の友人プレイで、説明なしでも受け渡しが迷わないか確認する。
- 広告SDK接続後に、秘密情報画面へ広告が出ないことを再確認する。

## 2026-06-05 追加確認

- 390 x 844のスマホ幅でトップ、プレイヤー設定、全ゲームsetupを確認した。
- ナンバートーク、ワンナイト人狼、日本マップ当てを4人で結果まで進めた。
- ワンナイト人狼の投票中に戻るボタンが表示されないことを確認した。
- 追加6ゲームは、3人ワード潜入者通し、4人開始条件、8人受け渡し/秘密表示を確認した。
- `npm run audit:storage` で、8人/全ゲーム代表sessionの保存サイズが9.68KiBで、保守的な2MiB予算を下回ることを確認した。

残り:

- iPhone Safari実機。
- Android Chrome実機。
- 実機低速回線での日本マップ当て画像ロード、リトライ、代替地点切替。
