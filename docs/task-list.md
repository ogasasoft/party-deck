# 実装タスクリスト

## 目的

`docs/user-stories.md`、`docs/system-design-units.md`、`docs/implementation-spec.md` を、実装・検証・リリース準備で追えるタスクへ分解する。

凡例:

- `[x]` 完了
- `[~]` 実装済みだが追加強化が必要
- `[ ]` 未着手

ここからは全国地点データよりも、実機QA、画像失敗時UX、広告/法務、テスト強化を優先する。
