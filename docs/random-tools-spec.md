# ランダムツール仕様

## 目的

飲み会やゲームの合間に、スマホ1台ですぐ抽選や判定を行える独立した便利ツールを提供する。ゲーム登録やラウンド進行には接続せず、ホームの「便利ツール」から開く。

## 共通方針

- 対象はルーレット、コイン、サイコロの3種類。
- 抽選結果は端末内で決定し、バックエンド、ログイン、履歴、送信機能は持たない。
- 対応ブラウザでは `crypto.getRandomValues` を使い、偏りを避けるため棄却法で整数へ変換する。非対応環境のみ `Math.random` へフォールバックする。
- ツール画面には広告を表示しない。
- アニメーションは結果を演出するだけで、結果自体は開始時に一度だけ確定する。
- `prefers-reduced-motion` が有効な端末では演出時間を短縮する。

## ルーレット

- 候補は1行に1件、空行と行頭・行末の空白を除外し、各候補は最大40文字かつ保存サイズ上限内へ正規化する。
- 候補数は2〜20件。21件目以降は抽選対象にしない。
- 登録済みプレイヤーのニックネームを候補へ一括入力できる。
- 各候補は同じ確率で選ぶ。
- 結果後に再抽選、選ばれた候補の除外、除外候補の一括復元ができる。
- 候補が2件になると、それ以上の除外はできない。
- 20件・各40文字へ正規化した候補テキストだけを `localStorage` の `party:v1:random-wheel-items` に保存する。結果と除外履歴は保存しない。
- 保存領域を利用できない場合も、その場の抽選は継続できる。

## コイン

- 表と裏を各50%で選ぶ。
- 投げている間の連打を無効化し、確定後は同じボタンで再実行できる。
- 結果は保存しない。

## サイコロ

- 1〜3個から個数を選べる。
- 各サイコロは独立に1〜6を同確率で選ぶ。
- 個別の出目と合計を表示する。
- 振っている間の個数変更と連打を無効化する。
- 結果は保存しない。

## テスト方針

- C0: 候補正規化、最大件数・文字数、Unicode書記素、乱数境界、各結果の範囲、不正入力、候補保存失敗時の継続を検証する。
- C1: ホームから開き、登録プレイヤーでルーレットを回し、コインを投げ、3個のサイコロを振れること、保存拒否時も抽選できること、結果通知領域が常設されることを検証する。
- UI QA: 390×844で操作、スクロール、結果表示、コンソールエラー、広告非表示を確認する。
