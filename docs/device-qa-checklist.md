# 実機QAチェックシート

更新日: 2026-06-05

## 目的

デスクトップのBrowser QAでは見えない、iPhone Safari、Android Chrome、低速回線、実広告有効化後の問題を実機で確認する。

このチェックシートは、確認したら `docs/task-list.md` と `docs/table-game-expansion-task-list.md` の該当項目を更新する。

## 事前準備

- URL: `https://party-deck.vercel.app`
- 端末を縦向きにする。
- 可能なら通常回線と低速回線の2回見る。
- 端末の戻る操作、ブラウザ戻る、リロードを試す。
- 友人テスト前は、実機確認後に `npm run audit:production` を通す。
- AdSense有効化後は `npm run audit:production:ads` も通す。

## iPhone Safari

対象タスク:

- `P8-01`
- `TGE-9-04`

確認項目:

- トップに `日本マップ当て`、ナンバートーク、ワンナイト人狼、追加ゲーム、飲み会ゲーム辞典が表示される。
- プライバシーと利用規約リンクが開ける。
- プレイヤーを2人から8人まで増減でき、入力欄が横にはみ出さない。
- ナンバートークの数字確認中にブラウザ戻る/リロードをしても、前の数字が直接表示されない。
- ワンナイト人狼の役職確認、夜確認、投票中にブラウザ戻る/リロードをしても、前の秘密が直接表示されない。
- 日本マップ当ての回答中に、前プレイヤーのピンが次プレイヤーへ見えない。
- 追加6ゲームの秘密表示/秘密投票中に、ブラウザ戻る/リロードで前プレイヤーの秘密や投票先が見えない。
- タップできるボタンが小さすぎない。
- 画面下部のSafari toolbarに主要ボタンが隠れない。

合格基準:

- 秘密情報が戻る操作で露出しない。
- 横スクロールが発生しない。
- 結果まで進行不能になる画面がない。

## Android Chrome

対象タスク:

- `P8-02`
- `TGE-9-05`

確認項目:

- トップ、プレイヤー設定、全ゲームsetupが縦画面で読める。
- ナンバートーク、ワンナイト人狼、日本マップ当てを4人で結果まで進められる。
- 追加6ゲームのうち、ワード潜入者と価値観メーターを結果またはラウンド結果まで進められる。
- Androidの戻るボタンで秘密確認や投票へ戻っても、前の秘密が直接表示されない。
- リロード後に秘密画面ではなく受け渡し/安全な画面へ戻る。
- プライバシーと利用規約リンクが開ける。

合格基準:

- Android戻るボタンで秘密漏れしない。
- 入力欄、スライダー、地図タップが普通に操作できる。

## 低速回線

対象タスク:

- `P8-05`

確認方法:

- 実機の通信を低速にする、またはChrome DevToolsのNetwork throttlingで代替する。
- 日本マップ当てを開始する。

確認項目:

- 地点画像の読み込み中にユーザーが待てる表示になっている。
- 画像が表示されるまで `地図を開く` が押せない。
- Mapillary画像が表示されたら `地図を開く` が押せる。
- 画像取得失敗時に `再試行` または `別の地点に切り替える` の導線が分かる。
- 1人でも回答後は地点が切り替わらず、公平性が保たれる。

合格基準:

- 画像ロードが遅くてもゲーム進行が壊れない。
- 失敗時に詰まらない。

## AdSense有効化後

前提:

- `VITE_ADSENSE_CLIENT`
- `VITE_ADSENSE_SLOT`
- 必要地域の同意管理

確認項目:

- ホーム、プレイヤー設定、ゲーム設定、結果画面にだけ広告が出る。
- 受け渡し、秘密確認、回答中、投票中、夜行動中、描画中に広告が出ない。
- 広告読み込みが失敗してもボタン操作、タイマー、地図、投票が止まらない。
- `/privacy.html` と `/terms.html` が200で表示される。
- `npm run audit:production` が通る。
- `npm run audit:production:ads` が通る。

合格基準:

- 広告が秘密情報や回答操作を邪魔しない。
- 法務ページが公開されている。
